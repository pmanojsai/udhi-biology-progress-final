# Udhi Biology Dashboard

I prioritised a clear "What to study next" section so students immediately know their highest-value action.
Topics are grouped by mastery so strong, developing, and weak areas are easier to scan.
Not-started topics are shown separately rather than being presented as misleading 0% mastery.
I used an AI coding agent to accelerate implementation and UI iteration.
The AI initially treated not-started topics like normal 0% progress, which I caught and changed to a separate state.
